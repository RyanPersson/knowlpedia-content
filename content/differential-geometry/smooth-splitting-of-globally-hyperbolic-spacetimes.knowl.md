Every [[differential-geometry/globally-hyperbolic-spacetime|globally hyperbolic spacetime]] \((M,g)\) admits a smooth Cauchy temporal function \(t:M\to\mathbb R\): its gradient is timelike and each level set
\[
\Sigma_s=t^{-1}(s)
\]
is a smooth spacelike [[differential-geometry/cauchy-hypersurface|Cauchy hypersurface]].

Choosing one level \(\Sigma\) gives a diffeomorphism
\[
M\cong\mathbb R\times\Sigma
\]
under which
\[
g=-\beta\,dt^2+h_t,
\]
where \(\beta>0\) is smooth and \(h_t\) is a smooth family of Riemannian metrics on \(\Sigma\). Conversely, a spacetime carrying a Cauchy temporal function is globally hyperbolic.
