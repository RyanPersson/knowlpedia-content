A **bijective function** is a [[shared-foundations/function|function]] \(f:A\to B\) that is both [[shared-foundations/injective-function|injective]] and [[shared-foundations/surjective-function|surjective]].

## Remarks

A function is bijective if and only if it has a two-sided [[shared-foundations/inverse-function|inverse function]]. Two sets have the same [[shared-foundations/cardinality|cardinality]] precisely when a bijection exists between them.

## Examples

- The function \(f:\mathbb Z\to\mathbb Z\), \(f(n)=n+1\), is bijective.
- The map \(\{1,2,3\}\to\{a,b,c\}\) defined by \(1\mapsto a\), \(2\mapsto b\), and \(3\mapsto c\) is bijective.
